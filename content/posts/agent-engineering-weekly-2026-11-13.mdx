> **统计窗口**：2026-11-06 至 2026-11-13（周五至周五，Asia/Shanghai，截止 11 月 13 日 23:59）。本期以 GitHub [Trending](https://github.com/trending) 为发现入口，使用具体仓库 README、GitHub Commit 记录作为事实依据。GitHub Trending 为动态榜单，仓库上榜与提交日期是两种指标；下文将“周期内确认提交”“持续值得学习”“学习延续”分别标记。部分 GitHub Commit 的 UTC 日期在北京时间可能落入相邻日，应以原始时间戳核对。

## 本周判断

1. **Runtime 竞争正在向可恢复操作靠近**：浏览器/桌面 Agent 要解决的是元素定位、动作验证、沙箱生命周期、环境隔离和用户授权。
2. **Skills 的价值逐步延伸到质量保证**：来自浏览器厂商的 Web 开发指导把最佳实践、静态分析和评测连接起来。
3. **Context 的重点是语义和来源可信度**：Agent 访问企业数据时，业务定义、跨 Schema 关系和引用来源直接影响结果质量。

这些判断是对公开代码变化的工程解读，并非项目方声明的行业结论。

## 一、Runtime / Browser / Desktop：操作与恢复

### [vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser) · 9.4/10 · P0

**作用与原理**：面向 Agent 的 Rust CLI。通过 `snapshot` 将页面变成带 ref 的简短可访问性结构，Agent 再通过 ref 执行操作，并二次读取页面确认变化。可与 TypeScript/Node Agent Loop 配合。

**本周可核实变更**：
- [修复滚动后点击坐标：2f533ec7](https://github.com/vercel-labs/agent-browser/commit/2f533ec7)（11/13 UTC）
- [修复异常停止后临时浏览器 Profile 遗留：d6e92bef](https://github.com/vercel-labs/agent-browser/commit/d6e92bef)（11/13 UTC）
- [为 Vercel Skill 加入 feature flag 覆盖：4720bc3d](https://github.com/vercel-labs/agent-browser/commit/4720bc3d)（11/13 UTC）

**学习重点**：页面状态快照、locator/ref 失效、动作前后验证、重试策略、独立浏览器会话。实践时记录每次工具调用的 input、snapshot 摘要、耗时与失败原因。

### [vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop) · 9.0/10 · P1

**作用与原理**：通过 macOS / Windows / Linux 的无障碍树读写桌面 UI；模型执行循环由上层 Agent 控制。桌面应用操作引入宿主权限、虚拟机/沙箱与敏感信息保护问题。

**本周可核实变更**：
- [macOS 客户机通信从 SSH 转向 guest agent：46d2adf8](https://github.com/vercel-labs/agent-desktop/commit/46d2adf8)
- [约束 host key 写入与探测响应：2a63c28b](https://github.com/vercel-labs/agent-desktop/commit/2a63c28b)
- [避免启动器退出导致沙箱停止：2f650705](https://github.com/vercel-labs/agent-desktop/commit/2f650705)

**学习重点**：Host/Guest 边界、最小权限、沙箱启动和清理、剪贴板/截图的隐私治理。先在测试应用中实验。

**本周可核实变更**：

**学习重点**：分支隔离、环境变量作用域、工作树生命周期，以及不同 Agent 宿主对 hooks 的兼容性。适合衔接此前学习的 [obra/superpowers](https://github.com/obra/superpowers) 和 Agent Harness 设计。

### [stablyai/orca](https://github.com/stablyai/orca) · 8.5/10 · P1

**本周可核实变更**：[桌面恢复窗口前请求用户许可：513aef5e](https://github.com/stablyai/orca/commit/513aef5e)；[浏览器点击弹窗时避免抢占用户焦点：34d9d372](https://github.com/stablyai/orca/commit/34d9d372)。
